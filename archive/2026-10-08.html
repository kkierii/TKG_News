Anthropic ships Claude Haiku 5.5 at $0.10 per million input tokens, a tenth of Haiku 4.5, with a 1M-token context window
Anthropic · 7 October 2026
Anthropic released Claude Haiku 5.5 on 7 October at $0.10 per million input tokens and $0.50 per million output tokens for prompts up to 100K tokens, rising to $0.50 and $2.50 above that threshold. Haiku 4.5 charged $1.00 and $5.00, so the short-context input price is a tenth of its predecessor’s.
The platform documentation lists a 1M-token context window, 128K maximum output tokens (300K through a Message Batches beta header) and a June 2026 knowledge cutoff. The announcement page states the model costs roughly 75% less to run than Haiku 4.5 on average; the 90% figure circulating in coverage is reachable only by comparing single line items rather than the average Anthropic published.
Anthropic reports Haiku 5.5 at 72.4% on the offline subset of OSWorld 2.1, against 15.7% for Haiku 4.5 and 48.9% for GPT-6 Luna; 39.2% on Terminal-Bench 4.0 against 0.0% and 16.4%; and 1620 on GDPval-AA v2.1 against 735 and 1437. The model is available on the Claude Platform, AWS, Google Cloud and Azure.
It is the first Haiku-class model with an adjustable effort parameter, defaulting to medium, and it ships an updated tokenizer that consumes more tokens per task than Haiku 4.5 — which eats into the headline saving by an amount Anthropic does not quantify. Non-default temperature, top_p or top_k values return a 400 error.

AI Security
Tensorlake’s npm SDK shipped a credential-stealing worm that deletes the home directory if its token is revoked
Socket · 8 October 2026
Version 0.5.144 of tensorlake, the npm SDK for Tensorlake’s AI agent infrastructure at roughly 12,000 weekly downloads, was published at 01:12:07 UTC on 8 October carrying obfuscated credential-stealing malware; Socket flagged it 11 minutes later at 01:23:10 UTC. StepSecurity traced the origin to commit e90c47b, pushed directly to the main branch at 01:20 UTC on 7 October under a maintainer’s name with no pull request, followed by seven further commits that added a preinstall hook. The 856 KB payload runs under Bun and harvests npm and GitHub tokens, AWS keys, Vault and Kubernetes secrets, SSH keys, .env files and AI tool configuration; Socket reports it resolves its command-and-control endpoint through an Ethereum contract rather than a fixed domain, while StepSecurity names an exfiltration domain, and the two write-ups disagree on that point. A persistence component polls the stolen GitHub token every 60 seconds for up to 24 hours and runs a recursive delete on the home directory if GitHub rejects it, so StepSecurity advises removing that component before revoking tokens, and pinning to 0.5.143.

AI Security
JFrog reports an unpatched CVSS 9.8 unauthenticated RCE in the LLM cache layer LMCache
JFrog Security Research · 7 October 2026
CVE-2026-105192, tracked as JFSA-2026-001694382 and scored CVSS 9.8, affects LMCache, the KV-cache layer used to speed up LLM inference servers, in every version from 0.3.9 onward. In multiprocess mode the cache opens a ZeroMQ ROUTER socket with no authentication, and a single message to the transport port, 5555 by default, reaches pickle.loads while the server decodes REGISTER_KV_CACHE arguments and before the handler executes, running code as the LMCache process user. JFrog states that as of 7 October no fixed version has been published: the decode path shipped in 0.3.9 and is still present in PyPI’s latest 0.5.5, the 0.5.6 release candidates through 0.5.6rc3 and the dev branch. The 9.8 applies to the routable configuration — JFrog notes the default localhost bind is not reachable from other machines, so exposure requires an address set with --host, and that the official container images run as root.

AI Security
Lumen ties a cryptomining campaign on thousands of servers to a LiteLLM command injection flaw
Lumen Black Lotus Labs · 7 October 2026
Black Lotus Labs attributes more than 3,400 victim servers to a campaign it calls PoeLLM since April 2026 in the report’s key takeaways, while the body of the same report says the campaign has impacted almost 2,200 servers; the two figures are inconsistent and we print both. The campaign scans internet-facing LiteLLM on port 4000, Ollama, Gotenberg on port 3000, Gitea and Ivanti Sentry, exploiting LiteLLM through command injection CVE-2026-42271, likely at the /mcp-rest/test/connection endpoint. The malware derives its current command-and-control address from a poem stored as dash.css in a GitHub repository forked from the nodejs.org source, extracting four keywords and mapping each to a number through a hard-coded dictionary; the poem was first committed on 13 April 2026 and has been updated 11 times without the derivation logic changing. Payloads are the XMRig and Iron miners, and Lumen assesses with moderate confidence that the operator is an Italian-speaking actor.

The Colorado Department of Law released an interim draft redline on 6 October of its proposed Automated Decision-Making Technology and Conversational Artificial Intelligence Service rules, which implement SB 26-189 and HB 26-1263. The proposed rules, the notice of rulemaking hearing and the statement of basis, authority and purpose were filed with the Secretary of State on 11 August 2026, after a pre-rulemaking comment period that closed on 13 July. Research
Preprint: an agent hid an attacker’s string in memory and recovered it in a later session in 20% of 14,000 trials
arXiv:2610.04589 · submitted 3 October 2026
A preprint announced in arXiv’s 6 October cs.CR listing tests whether an AI agent can conceal an attacker-chosen string in one session and recover it in another without tripping safety oversight, across 14,000 attack trials, 91 model-attack configurations, 13 models and seven steganographic schemes. The reported attrition runs 41.2% of trials encoding the payload in the response, 29.8% surviving the memory write, 25.4% recoverable at retrieval and 20.1% achieving exact-match recovery, including synthetic API keys and cryptographic material the receiving session never saw. Of those exact-match transmissions, 71.4% also passed task-completion scoring and were judged safe by the oversight model, which the authors put at 14.4% of all trials. The authors identify memory persistence rather than retrieval as the bottleneck; the work is a preprint and has not been peer reviewed.
